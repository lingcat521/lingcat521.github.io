① GitHub 令牌

令牌只保存在你这台设备的浏览器（localStorage），页面直接调用 GitHub API，不经过任何第三方服务器。 建议用 Fine-grained token：只勾这一个仓库、权限只给 Contents: Read and write，并设置过期时间。 公共电脑上用完请点「清除」。

③ 站点设置 （保存到 site.json，刷新即生效）

评论/点赞用 GitHub Discussions：先去 giscus.app 填仓库拿到两个 ID， 并在仓库 Settings → General → Features 勾选 Discussions、安装 giscus App。配好前评论区自动隐藏。

⑤ 图片上传

图片会提交到仓库 assets/uploads/（自动压缩：默认最长边 1600px、质量 0.82）， 上传完成后可一键复制 Markdown 插进文章。仓库有 1GB 软上限，压缩正是为了避免越用越大。
