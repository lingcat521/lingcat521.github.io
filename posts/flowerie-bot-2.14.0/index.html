🌸 花璃 v2.14.0 更新公告

这次补上了花璃一直缺的场景：私聊。

以前私聊消息和群聊混在一起处理：上下文串、记忆串、人格串—— A 在群里说的话可能影响 B 私聊时花璃的态度。这次按 QQ 号完全隔离。

💬 一、按 QQ 号完全隔离

  • 虚拟会话 key = -QQ 号：上下文 / 记忆 / 人格解析 / AI 预算 / 冷却

全部各人独立，互不可见、不与群聊混用

  • AI 能力与群聊一致：识图、内置工具、人格、花语记忆
  • 命令同样可用（/help /memory /forget /profile …），

回复自动走私聊通道；群管理指令在私聊里明确拒绝（私聊没有「群」可管）

🔒 二、默认关 + 允许名单

  • 默认关；允许名单为空时只允许 ADMIN_QQ_IDS 里的人
  • 临时会话 / 陌生人默认拒绝（不会跟陌生人瞎聊）
  • 每人同冷却、上下文条数、私聊记忆开关均可配（PRIVATE_CHAT_*）

🖥️ 三、Web UI「私聊」页

开关状态、允许名单编辑、每人记忆条数与一键清空——零 JS，热更新。

SDK/API 同步：Bot 新增 send_private / get_private_history / private_chat_status；插件动作补齐文档。

+14 单元测试（tests/test_private_chat.py）：隔离 / 允许名单 / 陌生人 / 冷却 / 记忆独立。
