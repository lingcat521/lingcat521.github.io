## 两种挂法

**个人站**（推荐）：仓库名必须是 `<用户名>.github.io`，网址就是 `https://用户名.github.io`，每个账号只能有一个。

**项目站**：在任意仓库里用 `gh-pages` 分支或 `/docs` 目录当发布源，网址是 `https://用户名.github.io/仓库名/`。

## 三条必须先知道的红线

- **只能静态**：HTML / CSS / JS / 图片。没有后端，不能跑 Python、PHP、数据库。
- **站点是公开的**：免费账号下 Pages 只对公共仓库开放，页面里千万别写密钥。
- **有额度**：站点 ≤ 1 GB、软带宽 100 GB/月、部署超 10 分钟会超时、每小时最多 10 次构建（用自定义 Actions 工作流部署不受这条限制）。

## 什么不能挂

任何需要「服务器一直开着」的东西都不行。比如我那个机器人的管理后台就绝对不能挂——它既要读写本地数据库，又涉及密钥和管理员账号。

## 那怎么在网页上发文章

静态站没有后端，但可以让浏览器直接调用 GitHub API 提交文件：令牌存在你自己的浏览器里，页面只负责把 Markdown 变成文章页，然后一次 commit 推上去。

本站的「后台」就是这么做的，代码只有几百行，没有任何第三方服务。

## 国内访问的小提醒

`*.github.io` 在国内不算稳定。要长期用，建议绑自己的域名再套一层 Cloudflare，会稳很多；GitHub Pages 支持自定义域并自动签发 HTTPS 证书。

## 多久生效

开启 Pages 之后一般一两分钟就能访问。新账号第一次用偶尔会慢一点，等着就行，别反复改配置。
