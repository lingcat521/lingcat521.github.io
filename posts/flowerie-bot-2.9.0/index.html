🌸 花璃 v2.9.0 更新公告

锵锵——这次是一个记人的版本。

以前花璃的记忆是「便签式」的：群友说一句「我喜欢喝奶茶」，花璃就记一张便签。 但谁是什么性格、最近在忙什么、说话是什么风格——这些拼不起来，聊着聊着还是 会把你叫错、接错梗。

这次加了群友画像：每天凌晨摘要跑完之后，花璃会再用同一份当天对话多跑 一次提炼，给当天有表现的群友建立/更新一份画像——性格 / 喜好 / 个人生活 / 特点，四个字段。

（简单来说就是——花璃终于记住你们是什么样的人了喵）

🧑‍🤝‍🧑 一、画像是怎么来的

  • 每天摘要（v2.8.0 的每日凌晨群聊摘要）成功之后，画像提取自动跟进，

复用同一段当天文本，不会多读一遍群聊

  • 提炼出来的是结构化档案，不是流水账：性格一行、喜好一行、个人生活一行、

特点一行，每人最多四行

  • 之后每次群聊，本群最近活跃成员的画像会注入对话上下文——

花璃知道该用熟悉的方式接谁的话

（注入的时候画像是「不可信数据」——花璃会读，但不会因为它变成另一个人喵）

🧠 二、三层记忆，各管各的

  • 记忆库（老功能）：按用户的事实便签，聊到就记，/memory 能看
  • 花语记忆：按群的语义检索，翻历史聊天用的是它
  • 群友画像（新）：按群的结构化人物档案，每天集中整理一次

三者互补：便签记小事，检索翻历史，画像认人。

🔁 三、画像会更新，也会过期

  • merge 语义：今天又提到某个字段就覆盖旧的；没提到的原样保留

（昨天说喜欢猫，今天没提，那花璃还记得）

  • 字段级淘汰：某个字段超过 PROFILE_SECTION_TTL_DAYS（默认 30 天）

没人再提，就不再当作画像——「上个月说过喜欢 X」不会变成永远的人设

  • 手工也能改：Web UI 新增「群友画像」页，按群查看 / 修正 / 删除；

群里发 /profile 可以看花璃对自己的画像

🛡️ 四、安全边界

  • 画像是模型从群聊里提炼的（不可信来源）：落库前每个字段都过代码层闸门——

QQ 号 / 注入句式 / 指令关键词 / 换行 / 超长一律拒收

  • 注入对话前再清洗一次，手工改库的脏数据也兜得住
  • 提取失败（AI 故障 / 模型没输出合法 JSON）不影响摘要本身

📦 五、顺带把摘要也升级了（承接 v2.8.0）

  • 摘要缓冲拉到 12000 条/群，直接喂全量文本（反正 1M 上下文装得下）
  • 新增 DIGEST_SOURCE 分层：buffer（默认内存缓冲）/ archive

（读隐私存档 txt，跨重启也完整；存档没开就自动回落缓冲，不强迫开存档）

🧪 六、测试

  • 新增 25 个单元测试：存储 CRUD / merge 语义 / 字段级淘汰 /

提取容错（代码围栏、尾随文本、非法 JSON）/ 清洗闸门 / 注入渲染 / 命令输出

  • CI 三档 + ruff 全绿；架构行数上限与协议 Gate 基线全部守住
  • 新功能默认关（PROFILE_ENABLED=false），升级之后行为和以前一模一样

🌸 最后总结

v2.9.0 只做了一件事：让花璃记住你们是什么样的人。

想要的话，把 DIGEST_ENABLED=true 和 PROFILE_ENABLED=true 一起打开， 第二天凌晨花璃就会开始给群友们建档。

QQ 机器人的部分照旧：人设对话、识图、记忆、人格、表情包、主动聊天 都没动，插件协议与 AI 预算也保持原样。

感谢一直在用花璃、写插件、提问题和看公告的大家！

花璃还在运行，项目也还在慢慢变好喵。

—— 花璃 v2.9.0 🌸
