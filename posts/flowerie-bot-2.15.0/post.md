# 🌸 花璃 v2.15.0 更新公告

这次花璃长出了**搜索能力**——而且不要 key。

以前想让花璃查实时信息（新闻、价格、新版本）只能接 MCP server，
配 key、配 server、配白名单，门槛不低。这次把一个免 key 的
搜索引擎层**内置**进 AI 工具层：`web_search` / `web_fetch`。

---

## 🔍 一、引擎层（4 个免 key 引擎）

- DuckDuckGo HTML / DuckDuckGo Lite / Bing / SearXNG（6 个公共实例轮询）
- **失败感知回退链**：transient 错误重试一次、403/429 反爬冷却 60s、
  总预算 30s——一个引擎挂了自动换下一个
- Bing 反爬适配（`ck/a` 跳转解包 + 无结果缓存 SERP 判定）
- LRU 结果缓存（TTL 可配 0–5 分钟）、域名黑名单、安全搜索档

`web_fetch` 抓正文复用 MCP 同款 SSRF 防线（回环/私网拒绝）。

---

## 🛡️ 二、和 AI 工具层同款护栏

- 双闸开关：`AI_SEARCH_ENABLED` 配置 + 服务注入，缺一不可
- 结果按**不可信外部数据**处理：prompt 里明确标注、关键结论要核对来源
- 只在模型判断需要实时信息时调用；纯闲聊不调用

---

## 🖥️ 三、Web UI「网页搜索」页

- 引擎状态卡片（启用/停用一目了然）
- **试搜**：填关键词跑一次真实搜索，看结果回显
- **逐引擎自检**：手动触发，看每个引擎通不通、延迟多少
