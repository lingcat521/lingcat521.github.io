# 🌸 花璃 v2.13.0 更新公告

一个很小的版本，解决一个非常具体的问题：**手机上打开 Web UI，
顶部一排页签挤到换行、把内容顶到屏幕外**。

---

## 📱 导航抽屉（窄屏）

- ≤760px 时，页签导航收成 ☰ 抽屉：点开从左滑出，
  点遮罩或跳页签即关闭；宽屏（>760px）保持一行胶囊不变
- 实现是**纯 HTML+CSS**：隐藏 checkbox + label + `:has()`，
  **零 JavaScript**——和整个 Web UI 的零 JS 原则一致
- 旧浏览器不支持 `:has()` 时，用 `@supports` 兜底退化成可换行胶囊
  （不会坏，只是不收起来）

---

## 🪟 顺带修了一个 CSS 坑

液态玻璃主题的顶栏磨砂原本挂在 `.topbar` 上——
`backdrop-filter` 会给 `position:fixed` 创建包含块，
导致抽屉被限制在顶栏高度内、滑不出来。

改挂 `::before` 伪元素解决。

+3 单元测试：抽屉标记（checkbox/label/overlay）、CSS 关键规则与
`:has()` 兜底、页签齐全且无脚本。
