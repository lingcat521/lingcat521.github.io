花璃：一个 DeepSeek 驱动的 QQ 群聊机器人

2026-09-17·约 2 分钟 #项目#QQ机器人
目录

花璃是我写的一个 QQ 群聊机器人。目标是让她像一个真实的群友，而不是一个「关键词回复机」。

她都能做什么

  • 💬 聊天：@ 她、或者群里接话都行，人设是小恶魔系青梅竹马。
  • 👁️ 识图：图片、表情包、合并转发里的图，先走视觉模型描述再自然回复。
  • 🧠 记忆：按「用户 × 群」隔离的长期记忆，用户自己能查、能删。
  • 🎭 人格：内置三套（花璃 / 亚托莉 / 艾拉），支持完全自定义，还能按群绑定。
  • 🎲 主动发言：概率化的上下文接话，以及定时主动聊天，全部可配置。
  • 🔧 MCP 工具：需要查资料时调用外部工具，带白名单、限额与独立熔断。

技术上我比较得意的三点

双协议：OneBot v11 + Milky

最早只支持 OneBot v11，后来加了一层适配，把协议差异全部关在适配层里，业务代码不碰任何协议字段。换协议端不用改业务逻辑。

管理后台「零 JavaScript」

Web UI 全部由服务端渲染，纯 HTML + CSS，一行 JavaScript 都没有。理由很简单：我大多数时候是在手机上打开它，而无 JS 的页面在任何浏览器里表现一致，也不会因为一处脚本报错就白屏。

插件支持任意语言

插件协议是 stdin/stdout 上的 JSON-Lines，所以和语言完全无关。仓库里有 13 种语言的最小可运行插件，CI 里会真的编译并启动它们：

C · C++ · Go · Rust · Java · C# · Kotlin
PHP · Lua · Ruby · Perl · R · TypeScript

JVM、.NET 和 tsc 的产物不是可执行文件，所以用三行 shell 包一层；脚本语言加个 shebang 就行。
