# 🌸 花璃 v2.2.2222 更新公告

诶嘿w，花璃迎来了一次维护性更新～

距离上一个版本v2.2.2已经过去一段时间啦。这次没有继续无止境地堆新功能，而是主要针对协议兼容、插件运行、配置管理、Web UI 和项目维护进行了改进。

（虽然说是维护性更新，但改的东西好像也不少喵……）

---

## 📡 一、接入 Milky 协议

- 新增 Milky 协议支持（现在除了 OneBot 等协议外，也可以使用 Milky 协议连接 QQ 机器人）
- 新增 Milky 事件解析
- 新增 Milky 消息发送适配
- 新增 Milky WebSocket 连接适配

（简单来说，就是让花璃能认识新的“通讯语言”，不再只会一种协议喵）

---

## 🔌 二、插件支持更多编程语言

这次给插件系统增加了新的运行方式：

- 新增 `runtime: "exec"` 插件运行模式
- 支持使用其他编程语言编写插件
- 增加系统平台与 CPU 架构检查
- 增加插件编译入口大小限制（最大 32 MB）
- 自动处理插件文件执行权限
- 增加多语言黑盒测试

目前已经进行实际运行测试的语言包括：

C、C++、Go、Rust、Java、C#、Kotlin、PHP、Lua、Ruby、Perl、R、TypeScript

（以后不一定非要用 Python 写插件啦！只要能编译或运行，就有机会接入花璃）

（当然，语言支持不代表所有语言都拥有完全相同的开发体验，具体还是要看插件运行环境喵）

---

## ⚙️ 三、配置文件生成机制改进

这次重新整理了 `.env` 配置模板的生成方式。

- 配置模板现在根据统一的配置结构自动生成
- 共整理了 21 个配置分组
- 增加 165 条配置说明
- 自动标注必填配置、敏感配置和需要重启的配置
- 减少手动维护配置模板造成的遗漏
- 大幅精简启动文件中的旧配置生成逻辑

（以前配置说明和实际配置容易出现不同步的问题，现在尽量让它们从同一个地方生成，减少“代码改了但文档没改”的情况）

---

## 🖥️ 四、Web UI 默认启用

这次调整了 Web UI 的默认行为：

- Web UI 默认开启
- 默认仍然只允许本机访问
- 局域网访问仍需手动配置
- 首次启动时支持注册流程
- 端口被占用时会记录错误，但不会直接导致机器人退出

（开箱即用更方便了，但默认只允许本机访问，避免 Web UI 直接暴露到网络上）

---

## 🤖 五、默认模型配置统一

统一了聊天、视觉和违禁内容检测相关功能的默认模型：

- 默认模型调整为 `deepseek-flash`
- 聊天模型、视觉模型和违规检测模型的默认配置进行统一
- 已经存在的 `.env` 和 `settings.db` 配置不会被强制覆盖

（不会因为更新一次，就偷偷把你原来已经配置好的模型改掉喵）

---

## 🎨 六、Web UI 页面结构维护

这次对 Web UI 的页面文件进行了整理：

- 将 CSS 样式从 Python 字符串中移出
- 将 HTML 模板从 Python 字符串中移出
- 新增统一的静态文件访问路径
- 对静态文件名称进行限制
- 增加样式内容指纹
- 页面底部显示样式版本指纹
- 为 HTML 增加 `no-store` 缓存策略
- 补充 PyInstaller 打包时所需的静态文件配置

（以前部分页面内容直接写在 Python 里面，维护起来比较痛苦；现在把页面、样式和程序逻辑分开，改起来更清楚）

---

## 📱 七、Web UI 移动端适配

优化了 Web UI 在不同设备上的显示效果：

- 优化电脑端页面布局
- 优化平板设备显示
- 优化手机端显示
- 增加五档响应式布局断点
- 避免页面出现过大的固定宽度
- 修复部分表格样式问题
- 修复代码块和文本内容溢出问题
- 修复 `.row` 布局异常
- 增加宽度工具类
- 优化表单网格布局
- 优化群昵称管理卡片布局

（现在用手机打开 Web UI 时，页面不会那么容易挤成一团了）
