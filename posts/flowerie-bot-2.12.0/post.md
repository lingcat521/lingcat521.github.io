# 🌸 花璃 v2.12.0 更新公告

这次的大件：**花璃会自己动手了**。

以前花璃只会说话——想发说说得你点面板，想禁言得管理员敲命令。
v2.12.0 给模型加了一层「内置工具」（和 MCP 工具同一形状），
模型在一轮对话里可以**自己决定**调用哪个工具。

全部默认关、每个工具都有开关和护栏——这是设计前提，不是补丁。

---

## 🤖 一、工具清单（每个独立开关）

- `qzone_list_images`：列配图池 + 每张图的识图描述（按 mtime 缓存，省视觉额度）
- `qzone_post` / `qzone_delete`：AI 自己决定发什么、配哪几张图
  （图片必须来自配图池；每日额度、正文 ≤2000 字）
- `group_status` / `group_mute` / `group_unmute`：禁言/解禁
- `memory_recall`：主动回忆当前用户在本群的长期记忆

模型每轮用量也记账，和 MCP 工具共用熔断与预算。

---

## 🛡️ 二、护栏

- **群管理类**：发起人必须是群主/管理员，且 Bot 自己要有管理权限；
  单次禁言 ≤24h；不经过 LLM 二次确认直接拒绝
- **QQ空间类**：图片必须来自配图池（不能瞎填网址）、每日额度、
  正文长度上限；解析失败就不发
- **全开关默认关**：`AI_*_ENABLED` 全 false，升级后行为零变化

---

## 🌙 三、定时自主发动态

`AI_QZONE_AUTO_ENABLED=true` 后，后台任务每
`AI_QZONE_AUTO_INTERVAL_HOURS` 小时跑一次：

1. 扫配图池，用视觉模型生成/复用图片描述
2. 取最近群聊做素材（只作素材，不复述）
3. 让模型自己决定写什么、配哪几张图——**必须输出 JSON**
4. 解析不出 JSON 就**不发**（绝不猜内容）

异常不会打断主循环。
